# Changelog

## 0.1.0-beta.1

First public beta.

- Epic library with local cache, search, filters and sorting
- Installs from Epic's CDN with selective content, updates, verify & repair, uninstall
- Resumable download queue, speed limit, experimental multi-CDN
- Embedded sign-in, tokens encrypted with Windows DPAPI
- Tray icon, launch at startup, notifications, taskbar progress
- Self-update through GitHub Releases (stable and beta channels)
